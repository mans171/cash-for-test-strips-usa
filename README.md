# Cash For Test Strips USA

A directory for people to find local cash buyers for diabetic test strips.

## Setup

```bash
npm install
cp .env.example .env.local  # fill in your Supabase keys
```

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Next.js + TypeScript + Tailwind + App Router
- Supabase for click tracking, lead data, and company listings
- Deployed on Vercel
- Blog posts are MDX files or Supabase-backed for SEO
