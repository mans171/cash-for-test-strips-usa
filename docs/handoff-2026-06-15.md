## Important technical notes

- **Supabase writes:** The anon key can't write to the DB (RLS blocks it). Use Playwright to run SQL directly in the Supabase dashboard SQL editor — see memory for the exact pattern.
- **Vercel env vars:** `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` are set in the Vercel project for production.
- **Click tracking pattern:** All outbound links go through `/api/track?company=<id>&url=<encoded-dest>` — never link directly to buyer sites.
- **Server components:** All page routes are server components. Only `/directory/filters.tsx` is a client component (state dropdown uses `useRouter`).
- **Tailwind v4:** Uses CSS-based config (`@import "tailwindcss"` in globals.css), no `tailwind.config.js`.
